## 📐 Technical Specifications

### iOS Screenshot Requirements
**iPhone 6.7" (iPhone 14 Pro Max)**:
- **Resolution**: 1290×2796 pixels
- **Format**: PNG or JPEG
- **Color Space**: sRGB or Display P3
- **File Size**: <8MB per image
- **Quantity**: 3-10 screenshots (5 recommended)

**iPhone 6.5" (iPhone 14 Plus)**:
- **Resolution**: 1242×2688 pixels
- **Same requirements as above**

**iPad Pro 12.9" (6th gen)**:
- **Resolution**: 2048×2732 pixels
- **Landscape and Portrait orientations**

### Android Screenshot Requirements
**Phone Screenshots**:
- **Minimum**: 320px on shortest side
- **Maximum**: 3840px on longest side
- **Aspect Ratio**: Between 2:1 and 1:2
- **Recommended**: 1080×1920 pixels (phone portrait)
- **Format**: JPEG or 24-bit PNG
- **Quantity**: 2-8 screenshots

**Tablet Screenshots**:
- **7-inch**: 1024×600 pixels
- **10-inch**: 1920×1200 pixels

## 🎨 Visual Design Guidelines

### Overall Design System
**Color Palette**:
- **Primary**: #1e40af (Royal Blue)
- **Secondary**: #3b82f6 (Bright Blue)
- **Accent**: #fbbf24 (Gold)
- **Neutral**: #64748b (Slate Gray)
- **Background**: #f8fafc to #e2e8f0 (Light Gray Gradient)

**Typography**:
- **Headlines**: SF Pro Display Bold (iOS) / Roboto Bold (Android)
- **Subtext**: SF Pro Text Medium (iOS) / Roboto Medium (Android)
- **Body**: SF Pro Text Regular (iOS) / Roboto Regular (Android)
- **Sizes**: Scale appropriately for screenshot resolution

**Layout Principles**:
- **Hierarchy**: Clear visual hierarchy with headlines, subtext, callouts
- **Spacing**: Generous white space, 16px base unit
- **Alignment**: Consistent grid system, left-aligned text
- **Balance**: 60/40 or 70/30 content splits

### Device Mockups
**iPhone Models**:
- Use latest iPhone models (iPhone 14 Pro Max primary)
- Realistic shadows and reflections
- Proper perspective and proportions
- High-quality device frames

**Camera Equipment**:
- Professional-grade cameras (not point-and-shoot)
- Clean, new condition appearance
- Proper brand representation
- Studio lighting quality

### Photography Standards
**Image Quality**:
- **Resolution**: Minimum 4K for source images
- **Sharpness**: Tack sharp, professional focus
- **Exposure**: Perfect exposure, full dynamic range
- **Color**: Accurate, vibrant but not oversaturated
- **Composition**: Professional composition rules

**Content Guidelines**:
- Avoid copyrighted or stock photo appearance
- Use diverse subjects and scenarios
- Ensure all people in photos have signed releases
- Maintain brand consistency across all images

## 🔧 Production Workflow

### Design Phase (Week 1)
1. **Concept Development**:
   - Sketch initial layouts
   - Define messaging hierarchy
   - Select photography assets
   - Create style guide

2. **Asset Collection**:
   - Photograph camera equipment
   - Capture app interface screenshots
   - Source or create background images
   - Prepare device mockups

### Production Phase (Week 2)
1. **Layout Creation**:
   - Build master templates
   - Implement design system
   - Create text overlay styles
   - Establish spacing/alignment

2. **Content Integration**:
   - Composite all visual elements
   - Apply text overlays
   - Optimize for each platform
   - Create size variations

### Testing Phase (Week 3)
1. **Quality Assurance**:
   - Test across different devices
   - Verify text readability
   - Check color accuracy
   - Validate file formats

2. **A/B Test Setup**:
   - Prepare variant versions
   - Set up testing framework
   - Define success metrics
   - Launch soft launch tests

### Optimization Phase (Week 4)
1. **Performance Analysis**:
   - Analyze conversion data
   - Gather user feedback
   - Identify best performers
   - Document insights

2. **Final Implementation**:
   - Apply winning variations
   - Prepare for global launch
   - Create production assets
   - Archive source files

## 📱 Platform-Specific Considerations

### iOS App Store
**Unique Requirements**:
- Higher quality expectations
- Premium aesthetic important
- Feature-focused messaging
- Technical capability emphasis

**Optimization Tips**:
- Lead with most compelling screenshot
- Use device frames sparingly
- Emphasize iOS integration
- Professional appearance critical

### Google Play Store
**Unique Requirements**:
- More diverse device audience
- Value proposition clarity important
- Broad appeal necessary
- Competitive differentiation key

**Optimization Tips**:
- Clear benefit statements
- Multiple device types shown
- Price value emphasis
- Feature accessibility highlighted

### Localization Considerations
**Text Overlays**:
- Plan for text expansion (German +30%)
- Consider right-to-left languages
- Cultural color considerations
- Local photography preferences

**Visual Elements**:
- Avoid text-heavy screenshots for easy localization
- Use universal visual symbols
- Consider local photography styles
- Adapt color schemes for markets

This comprehensive screenshot specification ensures Camera Companion presents its strongest possible case for download conversion across all platforms and markets.
